Drop the finished card graphics here with these exact names
(all three are أكتوبر ٢٠٢٤):

  potm-1.jpg   →  عبدالله كمال      · S  · فئة 2014
  potm-2.jpg   →  أمجد أبو مندوق    · RB · فئة 2010

These are saved directly from the finished shield-card graphics
(the ones already showing rating, position, name, flag and squad
year) — not a plain headshot. The page just frames whatever image
is in each slot, so the full card renders as-is.

Notes
-----
* Any reasonable size works — the frame shows the whole image
  (no cropping) and centers it.
* A missing file is not an error — the card falls back to the A10
  crest watermark, so the section never renders broken.
* To add more months, add entries to PLAYERS_OF_MONTH in
  src/A10Academy.jsx and update PLAYERS_OF_MONTH_LABEL.
